# Assets

Public academy/press photos are currently embedded from their publicly available source URLs and credited inline. See `public-media-sources.md` for sources, context and rights notes. They are not downloaded into this bundle because outbound image downloads are blocked in this environment.

## Official crest

The actual Gelvandale crest image was not included in the supplied project files. The header, mobile menu and footer try the expected public path `/gelvandale-rugby-academy-crest.jpg`, then the local path below:

- `gelvandale-rugby-academy-crest.jpg` (root or `/assets/`)

If those paths do not contain the official image, the site displays a shield-shaped `GRA` monogram as a clearly provisional fallback. That monogram is not represented as the official crest. Replace it with the academy-approved crest file before launch.
